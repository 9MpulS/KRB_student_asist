# Загальна інформація

Ласкаво просимо до документації проєкту **KRB Student Assistant**.
Цей асистент розроблений для допомоги студентам СумДУ у пошуку відповідей на запитання щодо нормативних документів університету.

Система базується на архітектурі **Retrieval-Augmented Generation (RAG)** і використовує сучасні технології, такі як **FastAPI**, **PostgreSQL (pgvector)** для зберігання ембедінгів та **Elasticsearch** для повнотекстового пошуку.

Ви можете ознайомитися з інтерактивною документацією API Swagger UI на [http://localhost:8000/docs](http://localhost:8000/docs) під час запуску локального сервера.
