# Архітектура та Бізнес-логіка

## Загальна інформація про RAG

Цей застосунок використовує архітектуру **Retrieval-Augmented Generation (RAG)**, що дозволяє отримувати точні відповіді на запитання, спираючись виключно на заздалегідь проіндексовані документи:

1. **Індексація (Indexing)**: Документи (PDF, Word тощо) завантажуються, парсяться на текст і розбиваються на менші фрагменти (чанки).
2. **Векторизація (Embedding)**: Кожен чанк перетворюється у математичний вектор за допомогою локально розгорнутої моделі Ollama (`paraphrase-multilingual`). Вектори зберігаються у базі даних PostgreSQL з використанням розширення `pgvector`.
3. **Повнотекстовий пошук (FTS)**: Паралельно тексти відправляються в Elasticsearch для швидкого пошуку за ключовими словами, що доповнює векторний пошук.
4. **Пошук при запиті (Retrieval)**: Коли користувач ставить питання, воно теж векторизується. Система паралельно шукає найближчі вектори у PostgreSQL і найбільш відповідні фрагменти в Elasticsearch.
5. **Ранжування (Reranking)**: Знайдені з обох джерел фрагменти фільтруються та оцінюються великою мовною моделлю (LLM) через Groq API (LLaMA 3) з метою відкидання "сміття".
6. **Генерація (Generation)**: Найрелевантніші фрагменти збираються як контекст у великий промпт, і LLaMA 3 генерує кінцеву відповідь, вказуючи джерела.

## Test-Driven Documentation (TDD) Example

Ми використовуємо підхід TDD у нашій документації, гарантуючи, що код, показаний тут, працює коректно.

Ось приклад роботи моделі питання-відповіді з нашого пакету Pydantic (`src/schemas/question.py`):

```python
>>> from src.schemas.question import QuestionResponse
>>> response = QuestionResponse(
...     answer="Згідно з положенням...",
...     sources=["Положення про організацію освітнього процесу (стор. 12)"],
...     context="Контекст з документа"
... )
>>> print(response.answer)
Згідно з положенням...
>>> print(response.sources[0])
Положення про організацію освітнього процесу (стор. 12)
```

Ці приклади також можна перевіряти автоматично за допомогою модуля `doctest` стандартної бібліотеки Python.
